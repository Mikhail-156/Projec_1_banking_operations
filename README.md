# Курсовая работа (1)

#### Описание и цель проекта

Проект представляет собой приложение для анализа банковских операций, которое хранится в Excel-файле. 
Применение JSON-данных для веб-сайтов, а также предоставляет другие сервисы.


### 1. Веб-страницы
Данные для анализа и результатов на веб-страницах — это данные с начала месяца, когда выпадает следующая дата, по входной дате.

#### Страница «Главная»
Приветствует пользователя в зависимости от текущего времени.
- Выводит информацию по всем картам, использованным за текущий (или последний) месяц: последние 4 цифры номера, общие расходы, кешбэк (1 рубль на женщину 100 рублей).
- Выводит топ 5 транзакций за месяц по суммам платежа.
- Выводит курс валют пользователя.
- Выводит стоимость акций пользователя.

### 2. Услуги
#### Простой поиск
Сервис ищет запросы, содержащие запросы в описании или категории.

### 3. Отчёты
#### Траты по категориям
Считает ведет по заданной категории за последние три месяца

## Установка

1. Клонируйте репозитории :
git clone git@github.com:Mikhail-156/Projec_1_banking_operations.git
2. Установите в зависимости:
pip install -r requirements.txt

## Использование
1. Для работы со своими транзакциями вы можете выгрузить и использовать часть файла из личного кабинета «Тинькофф Банка» («Т-Банка»). Для этого перейдите на официальный кабинет и зайдите в личный кабинет. После этого можно выгрузить.

2. Сохраните этот XLSX-файл в корневую директорию data/и запишите название файла в переменное окружение OPERATIONS (Пример оформления в файле .env.example).

3. Для работы с моими валютами и акциями запишите их в соответствующий файл user_settings.jsonв корневой директории проекта.

4. Запустите программу в модуле main.pyв корневой директории src/.

## Описание функций

### Модуль src/utils.py

1. Функция "greet_user" приветствуется пользователем в зависимости от текущего времени суток.

2. Функция "get_cards_numbers" поиска данных по каждой карте, использованной за текущий (последний) месяц:
- последние 4 цифры,
- важные расходы,
- кешбек.

3. Функция "get_top_transactions" поиска информации по 5 самым большим транзакциям за текущий (последний) месяц.

4. Функция "main_page_func" — основная функция для страницы «Главная».

5. Функция "read_from_xlsx" читает XLSX-файл с данными о транзакциях и возвращает их в виде списка словаря.

6. Функция "sort_by_period" сортирует транзакции по определенному периоду. При отсутствии транзакций за введенный период восстанавливаются платежи за последний присутствующий период.

### Модуль src/services.py

1. Функция "simple_search" поиска всех сообщений, содержащих запросы в описании или категории.

### Модуль src/reports.py

1. Функция "save_report" — декоратор для функций-отчётов, который записывает в файл результаты, формирующие возвращаемые функции, вызывающие отчёты.

2. Функция "spending_by_category" считает проведение по заданной категории за последние три месяца (отправленной даты). Если дата не передана, берется текущая дата. Если в эти три месяца нет в списке транзакций, возвращается 0 в потоках по стандарту.

### Модуль src/api_search.py

1. Функция "get_currency_rate" возврата валют в рублях.

2. Функция "get_currency_rate" возврата стоимости акций в долларах. Для получения стоимости в другой валюте необходимо добавить дополнительный параметр — курс доллара в этой валюте.

### Модуль src/views.py

1. Функция "create_report" записывает данные в JSON-файл.
